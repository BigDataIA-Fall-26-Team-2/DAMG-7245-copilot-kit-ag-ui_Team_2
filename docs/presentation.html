What is CopilotKit?

The chat UI, agent integration, and tool-rendering hooks. It provides the place where a tool call becomes an interactive card.

What is AG-UI?

The event protocol between agent execution and the UI. The adapter translates events such as tool-call arguments, text chunks, and run status into this format; SSE streams them to the browser.

The initial page and built JavaScript are served from EC2, but React and slider calculations execute in the browser. Nginx has response buffering disabled so agent output can arrive incrementally.

Show the actual projection rule
monthlyFactor = (1 + annualPercent / 100) ** (1 / 12)
balance = initialAmount
For each month:
  balance = balance * monthlyFactor + monthlyContribution
contributed = initialAmount + monthlyContribution * months
gain = balance - contributed
Defined in shared/savingsProjection.ts. The older growth tool instead uses nominal annual return / 12, so its rate convention is different.






Code map
Six visual tools, two team additions.
All six schemas, descriptions, and backend handlers are registered in server/src/vizTools.ts. All six UI mappings are in web/src/viz/renderers.tsx. A tool name is the contract connecting the two.


Explain is not a seventh backend tool. It is a UI button in ExplainCurrentScenario.tsx. scenarioMessage.ts builds its message. Suggested questions are predefined prompts in StarterQuestions.tsx, not extra agents or tools.


What the starter already handled
React chat, runtime endpoint, managed-agent adapter, event streaming, four visual tools, chart components, and hosted agent/environment configuration.
What our team added
Stocks/HYSA projections with display modes; savings goals; shared math and tests; current-scenario explanations and failure recovery; starter questions; and EC2 HTTPS deployment.


How does a new tool get added?
1. Add a schema, description, and handler in server/src/vizTools.ts. 2. Add a React card and renderer mapping. 3. Share calculation code where both backend and UI need the same result. 4. Test the math, then test an actual agent turn. The adapter registers these backend tools with sessions, so changing a custom visual tool does not itself require ant apply. Editing the hosted agent instructions does require publishing the new version and making the server use it.

Design choices
Capabilities and boundaries.


Why build this if ChatGPT or Claude can calculate it?
A general chatbot can solve the example. Our project demonstrates application integration: a structured tool call selects a known interactive component, tested code calculates its values, users change state without another model call, and Explain explicitly returns that state to the agent. The contribution is the interaction and implementation, not a unique financial formula.


Will “remove stocks” be remembered?
Within the same conversation, tool descriptions and returned results instruct the agent to retain displayMode: hysa. Follow-up calls should use it until changed. It is model-mediated session context, not a saved user profile or an absolute guarantee. A new chart is created; earlier cards do not change. A local Display selector affects its own card until you explicitly send that state back or state a preference in chat.


Where is conversation memory?
The browser holds the current transcript and per-card React state. EC2 holds an in-memory mapping from AG-UI thread IDs to hosted managed-session IDs. Anthropic holds hosted session context. Restarting the Node service loses the mapping. There is no saved-chat sidebar or persistent conversation catalog, and reloading the page does not reliably restore earlier chats. Hosted session context supports follow-ups; reopening saved conversations is a separate feature.


What happens if Explain fails?
The card shows a recoverable error and retains its local calculations. The handler listens to both failed-run events and promise rejection because CopilotKit can report an error without rejecting the promise. Retry sends a new message with current values; failed attempts remain in the transcript. Failure recovery was verified with a local backend outage and a successful retry.


Does every tool calculate on the backend?
No. The two new tools compute in shared application code and return numeric results to the agent. The original four backend handlers acknowledge rendering. Debt and growth compute in browser code; budget derives totals from supplied categories; generic comparison displays agent-supplied values. Generic comparison does not independently verify those values.


What was tested, and what is still limited?
18 automated tests cover the new math, input bounds, display modes, backend results, and message serialization. Typechecks and production build passed. Manual browser checks cover chart controls, preference follow-ups, suggestions, explanations, a forced backend failure and retry, and deployed HTTPS. These are not automated browser tests; GitHub CI is not configured. Model prose can still introduce extra assumptions. There is no persistent profile, bank integration, or production user authentication.
