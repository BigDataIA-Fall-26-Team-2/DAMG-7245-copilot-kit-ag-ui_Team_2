02 / The execution

The model chooses. The app executes.

“I have $500 saved toward $3,000 and can save $250 per month. Show my savings goal without interest.”



Tool selection ≠ chart rendering. Claude returns a named call. The backend runs its handler; streamed AG-UI events let CopilotKit map that name to a React component.
Logical stages, not a captured event log. Rendering and agent text may progress while events stream.
